# 筋トレ記録アプリ 設定手順

ファイルは2つです。

- `index.html` … 生徒が使うアプリ本体（スマホ・PCのブラウザで動きます）
- `Code.gs` … Googleスプレッドシートに記録と登録情報を保存するためのスクリプト

`index.html` だけをそのまま開いても動きますが、その場合は「テスト表示」になり、登録も記録もその端末の中にしか残りません。以下の手順でスプレッドシートとつなぐと、全員の記録がスプレッドシートに集まります。

## 1. スプレッドシートを用意する

1. Googleドライブで新しいスプレッドシートを作る（名前は例：「筋トレ記録」）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初から入っているコードをすべて消して、`Code.gs` の中身を貼り付ける
4. 保存ボタン（フロッピーのアイコン）を押す

## 2. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車アイコン →「ウェブアプリ」を選ぶ
3. 次のように設定する
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押し、Googleアカウントのアクセス許可を承認する（「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」で進めます。自分で作ったスクリプトなので問題ありません）
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーする

## 3. アプリにURLを設定する

`index.html` をテキストエディタで開き、次の行を探して、コピーしたURLを貼り付けます。

```js
const GAS_URL = '';   // ← '' の間にURLを貼る
```

## 4. 生徒に配る

スマホで使うには、`index.html` をインターネット上に置いてURLを共有する必要があります。例えば次のような方法があります。

- Netlify Drop（https://app.netlify.com/drop ）に `index.html` を入れたフォルダをドラッグ＆ドロップする
- GitHub Pages に置く
- 学校のWebサーバーや、使っているクラス用サイトに置く

URLを生徒に共有し、ホーム画面に追加してもらうと、アプリのように使えます。

## 使い方（生徒向け）

**はじめて使うとき**

1. 「はじめて使う（新規登録）」を選ぶ
2. 名前と、自分で決めた数字4けたの暗証番号（2回）を入力して「登録してはじめる」

**2回目から**

- 同じ端末なら、自動でログインされます
- ログアウトしたときや別の端末では、名前と暗証番号でログインします

**記録のしかた**

1. 日付を確認する（前回のトレーニングから何日空いたかが表示されます）
2. 部位 → 種目をえらぶと、説明・効く部位の図・注意点が表示される
3. 重量（2.5kg刻み）・回数・セット数をえらんで「記録を保存」
4. 「自分の履歴」タブで、日ごとの記録や種目ごとの自己ベストを確認できる

## 暗証番号のしくみ

- 名前の全角/半角・スペースの違いは区別されません（「山田 太郎」と「山田太郎」は同じ人）。
- 暗証番号は、元の数字ではなく変換した形で「ユーザー」シートに保存されます。先生がシートを見ても、暗証番号は分かりません。
- 5回続けて間違えると、10分間ロックされます（総当たりで試されるのを防ぐためです）。
- 自分の記録しか見られず、削除もできません。

## 先生向け：よくある対応

- **暗証番号を忘れた生徒**：スプレッドシートの「ユーザー」シートで、その生徒の行を削除します。生徒は同じ名前でもう一度「新規登録」すると、新しい暗証番号を決められます。これまでの記録は「記録」シートに残っていて、そのまま引き継がれます。
- **ロックされた生徒**：10分待つと解除されます。急ぐときは、「ユーザー」シートでその生徒の行の「失敗回数」「ロック解除(ms)」を 0 にします。
- **名前を間違えて登録した生徒**：「ユーザー」シートの行を削除し、「記録」シートの名前（D列）と名前キー（K列）を正しい名前に直します。
- **以前の版（ログインなし）で記録していた生徒**：同じ名前で新規登録すれば、それまでの記録がそのまま使えます。

## スプレッドシート側の見方

「記録」シートに1行1記録で並びます（ID／登録日時／日付／名前／部位／種目／重量／回数／セット数／総挙上量／名前キー）。フィルタやピボットテーブルで、部員ごと・種目ごとの集計ができます。1行目の見出しと列の順番は変えないでください。「ユーザー」シートは、暗証番号に関わる列を書き換えないでください。

## 注意点

- 登録は早い者勝ちです。本人より先に他の人がその名前で登録してしまうと、その人が本人の名前を使えてしまいます。URLは部内だけで共有し、最初に全員が登録したら、ユーザーシートで名前を確認してください。
- 暗証番号は4けたの数字なので、銀行のような強いセキュリティではありません。部活内で、他の人の記録をのぞかれないようにするための仕組みです。
- `Code.gs` を書き換えたときは、「デプロイ」→「デプロイを管理」→鉛筆アイコン→バージョン「新しいバージョン」にして更新してください（URLは変わりません）。
- 種目の説明・注意点は一般的な内容です。実際のフォームや重量は、顧問の先生やコーチの指導を優先してください。
